# Cash App Clone

A Cash App-style UI clone originally implemented in Swift/UIKit.

## Android / Linux-friendly edition

This repository now also contains a self-contained browser/PWA demo under **android/**. It is designed for Android phones and Linux desktops and requires no iPhone or Mac.

Open `android/index.html` in a browser, or serve the repository with a static web server. The demo supports:

- Home screen and amount keypad
- Local demo balance
- Demo send flow
- Activity history
- Editable demo balance
- Offline caching / PWA installation support
- Browser localStorage persistence

**Important:** this is a UI/demo project. It does not connect to Cash App, process real payments, collect banking credentials, or move real money.

## Original iOS source

The original Swift/UIKit files remain in the repository root, along with the storyboard, assets, and fonts. Building that original Apple-platform app requires Xcode on Apple hardware.
